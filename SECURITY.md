# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Published releases | Latest only |

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Use [GitHub's private vulnerability reporting](https://github.com/Viswakarma116/sample-project/security/advisories/new) if it is enabled for this repository. Otherwise, contact the repository maintainers privately through GitHub.

Include a clear description, reproduction steps, affected versions, and any suggested mitigation. We will acknowledge valid reports as soon as practical and coordinate a fix and disclosure timeline with the reporter.
